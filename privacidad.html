Política de privacidad de VI Clips

Última actualización: 18 de noviembre de 2026.

Qué es

«VI Clips» es una herramienta privada que usan sus propios creadores para publicar en sus propias cuentas (YouTube, Instagram, Facebook) los vídeos cortos que ellos mismos graban y editan. No es una aplicación abierta al público y no la usan otras personas.

Qué datos usa

  • Google / YouTube: con el permiso que el titular del canal concede, la aplicación sube vídeos a su propio canal y lee las estadísticas de esos vídeos (visualizaciones, «me gusta», retención).
  • Meta (Instagram / Facebook): con el permiso del administrador, publica Reels en la cuenta y la página propias y lee sus estadísticas.
  • No se accede a datos de otras personas, ni a mensajes, contactos o información de los espectadores.

Dónde se guarda y con quién se comparte

Las credenciales y las estadísticas se guardan en un servidor privado de los creadores, en archivos con acceso restringido. No se venden, no se ceden y no se comparten con terceros. Los datos de las API de Google se usan solo para la función descrita y cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el permiso y borrar los datos

El titular puede retirar el acceso en cualquier momento desde myaccount.google.com/permissions (Google) o desde la configuración de integraciones empresariales de Facebook (Meta). Al retirarlo, las credenciales dejan de funcionar, y se borran del servidor a petición del titular.

VI Clips Privacy Policy

Last updated: November 18, 2026.

«VI Clips» is a private tool used only by its own creators to publish the short videos they record and edit to their own accounts (YouTube, Instagram, Facebook). With the account owner's permission it uploads videos to the owner's own channel/page and reads those videos' statistics. It does not access anyone else's data. Credentials and statistics are stored on the creators' private server in access-restricted files, are never sold or shared, and Google API data is used only for this purpose in compliance with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions (Google) or in Facebook's Business Integrations settings (Meta); credentials then stop working and are deleted from the server on request.
